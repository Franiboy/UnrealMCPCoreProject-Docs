Extend with Custom Tools
Add project-specific MCP tools in pure C++, auto-discovered via Unreal reflection, zero registration
1
Define Your Toolset
Subclass UMCPToolset and declare static UFUNCTIONs. Each function becomes an MCP tool. @param comments become schema descriptions.
MyProjectToolset.h UCLASS(Hidden)
class UMyProjectToolset
  : public UMCPToolset
{
  /** @param bp_path Asset path */
  UFUNCTION(BlueprintCallable,
    Category = "MyProject")
  static FMCPToolsetResult
    get_character_health(
      const FString& bp_path);
};
2
Implement & Return JSON
Use FMCPToolsetResult::Success() or ::Error(). Add meta=(Mutating) for tools that modify state. The server auto-wraps them in undo transactions.
MyProjectToolset.cpp FMCPToolsetResult
UMyProjectToolset::get_character_health(
  const FString& bp_path)
{
  auto R = MakeShared<FJsonObject>();
  R->SetNumberField(
    TEXT("max_health"), 100.0);
  return FMCPToolsetResult::Success(
    MCPJsonHelpers::SerializeCompact(R));
}
3
Rebuild & Call
Rebuild the project. The plugin auto-discovers your toolset at startup via UObject reflection. No registration, no schema. Just works.
AI agent calls your tool {
  "method": "tools/call",
  "params": {
    "name": "get_character_health",
    "arguments": {
      "bp_path":
        "/Game/Characters/Hero"
    }
  }
}
